# Homebrew tap for the AgentDB CLI

```bash
brew install gleert/agentdb/agentdb
agentdb login
agentdb mcp install claude
```

Upgrade: `brew upgrade agentdb`. The binaries are downloaded from `https://alpha.agentdb.link/downloads/cli/` and checked against the SHA-256 sums in `Formula/agentdb.rb`.

AgentDB is in alpha: store only test or non-sensitive data. More: https://agentdb.link
